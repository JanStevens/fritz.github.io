Hello :wave:, welcome to my [personal website](https://janstevens.dev) source code!

This website runs on GitHub and uses a free Cloudflare account (for SSL and caching) in front of it. Using Astro, a static HTML version is created from this source code and deployed automatically with GitHub Actions to GitHub Pages.
